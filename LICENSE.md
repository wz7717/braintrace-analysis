# BrainTrace analysis licences

For the terms recorded for a particular file, look up its path in the public file manifest and read the `terms` column. [Public file manifest](PUBLIC_FILE_MANIFEST.csv)

## Code

The B17 sources and their documented derivatives carry the B17 MIT notice. For other analysis and plotting code, the analysis licence guide identifies the covered components and their notices. Third-party software retains its own licence. [B17 MIT licence](analysis/code/b17/LICENSE) · [B17 source versions](analysis/code/B17_SOURCE_VERSIONS.csv) · [Analysis licence guide](analysis/docs/LICENCES.md) · [Existing science MIT notice](analysis/licenses/BrainTrace_science_MIT.txt)

## Models and references

Within the listed human and macaque assets, CC BY-NC 4.0 covers only contributions the project licensor owns or has authority to license. Data and annotations from other sources retain their own terms. For the Ensembl 97 macaque references, consult the current release notice. Historical file lists identify the versions they cover. [CC BY-NC 4.0 licence](software/licenses/CC-BY-NC-4.0.txt) · [Human asset terms](software/notices/human_fixed/PROJECT_CONTRIBUTION_TERMS.txt) · [Macaque asset terms](software/notices/macaque_fixed/PROJECT_CONTRIBUTION_TERMS.txt) · [Release notice](software/NOTICE.txt)

## Third-party data and annotations

Allen RNA-seq files follow the Allen Institute’s terms. The mapping credits identify the Bo et al. supplementary gene catalogue under CC BY 4.0 and the Ensembl homology export under Ensembl’s terms. The separately supplied Bo count matrix, variance-stabilized expression matrix and specimen workbook have their own access conditions. [Allen source and terms](sources/allen_ahba/SOURCE_CREDITS.csv) · [Bo and Ensembl mapping credits](sources/ahba_mapping/SOURCE_CREDITS.csv) · [Data access and applicable terms by source](DATA_ACCESS_AND_LICENCES.md)
