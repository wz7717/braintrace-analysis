# Licence and provenance

The B17 original licence and copyright notice are in [code/b17/LICENSE](../code/b17/LICENSE). The project author confirmed MIT for the precise twelve original B17 source files on 2026-11-08. [B17 source versions](../code/B17_SOURCE_VERSIONS.csv) list eight exact originals and four already-prepared path-only derivatives. The MIT grant on the originals permits modification and distribution subject to preservation of its notice. The derivative entries record their changed SHA-256 values and keep that notice. Their changes select existing runtimes or output locations.

The frozen B17 CSV is a project aggregate. The integrated S31/S32 routines, ACT replay code and the plotting-only entries have file-level source/hash provenance. Preserve the [existing science MIT notice](../licenses/BrainTrace_science_MIT.txt) for the covered components, including the inherited AHBA excerpt and ACT helper where applicable. The project candidate scope for the added entries and data is recorded separately. Allen AHBA processed targets and study metadata use the provider's terms; the original Bo source inputs and centroid array have separate conditions.
