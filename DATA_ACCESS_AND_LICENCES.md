# Data access and applicable terms

| Object | Access and applicable conditions |
| --- | --- |
| B17, S31–S33 and plotting code | The project entries and figure sources are identified by version and checksum. Preserve the existing MIT notices for the B17 sources, the MIT-covered components of the project code, and the inherited AHBA functions. The current redistribution candidate records the project scope for each added entry. Model assets, inputs, saved data and third-party packages follow their own terms. |
| Frozen macaque software | The 120-reference application and assets retain their existing software, model and source notices. CC BY-NC 4.0 applies to the specified project model and data contributions; do not extend it to upstream assets. The fixed Network state, gene order and weights also match the AHBA route components. |
| Fixed human software | Five fixed human files with linked training provenance have pinned existing-release paths and exact hashes in the software source table. Use the original release and its applicable terms. |
| Original AHBA RNA-seq and staged maps | Allen's two official RNA-seq ZIPs retain provider bytes. The scientific maps include the Bo article's CC BY 4.0 gene catalogue with historical corrections and the specified Ensembl BioMart export on its terms. Both maps retain their locked CRLF staging. |
| AHBA post-transform target | The array contains transformed Allen Human Brain Atlas data. The index uses publicly published Allen specimen-group keys plus the frozen study classifications. Use Allen's noncommercial research, attribution and Freedom to Innovate terms. No Bo training expression or centroid array is provided in this component. |
| Bo source, frozen B5 and centroids | Obtain the original study reads through PRJNA905082. The processed original count, VSD and spreadsheet files have separate supplier conditions. The packaged gene axis and existing software assets have distinct scopes. The frozen B5 matrices, row bindings and donor-equal Pearson centroids require project/source authorization for the exact recipient and use. |
| Allen ACT processed inputs | The official portal supplies study data and publicly de-identified record metadata. The linked project selection, per-specimen outputs and donor summary are kept by the corresponding authors under the project scope. The replay codes, gene background, configuration and regional evidence are included here. |
| Allen ACT original reads | Request controlled original RNA-seq from NIAGADS accession NG00059 under its approval and DARM process. The processed TPM replay uses the Allen original TPM files. |
| GTEx, HPA, GEO and PsychENCODE | Follow each original provider's terms and accession. The recorded source URLs identify upstream study content. Exact project derivative matrices, frozen masks, splits, selection, inputs and labels follow the route-level access requirements. |
| Publication figure inputs | The figure tables contain stored aggregate values and interval endpoints only. Their source and extraction are recorded per file. Python and artwork fonts retain their own licences. |
